# Dynamic Notch

Кастомная динамическая челка для macOS, расширяющая возможности стандартного выреза экрана.

Проект создан на основе открытых проектов [Boring Notch](https://github.com/TheBoredTeam/boring.notch) и [Vibe Island](https://github.com/vibe-island), переработан под личное использование с фокусом на удобство, стабильность и интеграцию с рабочими инструментами.

---

## Внесённые изменения и особенности

### 1. Интеграция с консольными ИИ-агентами (Claude Code, Codex и др.)
- Встроен локальный Unix Domain Socket сервер (`~/.boring-notch/run/boring-notch.sock`) для связи с CLI-агентами.
- Отображение текущего статуса работы агента, активного инструмента и ветки Git в челке.
- Возможность отвечать на интерактивные вопросы агента (`AskUserQuestion`) и подтверждать опасные команды (Bash, правка файлов) прямо из челки в один клик.

### 2. Адаптивная геометрия челки и навигация
- Высота челки сделана полностью динамической под фактический контент экранов (через `PreferenceKey`), устранены фиксированные размеры и пустые черные пространства.
- Плавающая навигационная капсула снизу челки зафиксирована на строго одинаковом расстоянии (8px) на всех вкладках без наложений на контент.
- Единая область ховера вокруг челки и панели навигации предотвращает случайное захлопывание при движении курсора.

### 3. Компактный медиаплеер
- Компактный размер челки в режиме плеера (390px) со сгруппированными элементами управления.
- Реальное отображение времени и хода трека в реальном времени через `TimelineView`.
- Автоматическое определение источника звука и отображение нативной системной иконки приложения (Apple Music, Spotify, Яндекс Музыка, Safari, Chrome и др.).
- Поддержка управления сторонними плеерами (Яндекс Музыка и браузеры) через отправку глобальных системных медиа-команд.

### 4. Дровер вывода звука и микшер приложений
- Быстрое переключение системных аудиовыходов (встроенные динамики, наушники, AirPods).
- Список приложений фильтруется через ядро CoreAudio, отображая только те программы, которые действительно воспроизводят звук.
- Рабочее регулирование громкости для активных источников.

### 5. Календарь
- Компактный двухколоночный вид: повестка дня и увеличенная, легко читаемая сетка месяца с отметками событий.

### 6. Замена системного HUD
- Возможность замены стандартных индикаторов громкости и яркости macOS на панели в вырезе челки (прямой перехват `CGEventTap`).

### 7. Локализация
- Полный русский перевод интерфейса челки, навигации, медиаплеера, панели агентов и окна настроек.

## Сборка

Для сборки требуется macOS 14.0+ и Xcode:

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -scheme boringNotch -configuration Debug build
```
