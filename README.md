# Dynamic Notch

Кастомная динамическая челка для macOS, расширяющая возможности стандартного выреза экрана.

Проект создан на основе открытых проектов [Boring Notch](https://github.com/TheBoredTeam/boring.notch) и [Vibe Island](https://github.com/vibe-island) и доработан под личное использование.

---

## Что добавлено и изменено

### 1. Интеграция с консольными ИИ-агентами (Claude Code, Codex и др.)
- Локальный Unix Domain Socket сервер (`~/.boring-notch/run/boring-notch.sock`) для связи с CLI-агентами.
- Отображение статуса работы, активного инструмента, проекта и ветки Git в вырезе челки.
- Ответы на интерактивные вопросы агента (`AskUserQuestion`) и подтверждение команд (Bash, запись файлов) в один клик прямо из челки.

### 2. Навигация в виде плавающей капсулы
- Меню переключения вкладок вынесено в нижнюю плавающую капсулу под челкой (Музыка, Календарь, Полка, Агенты) в стиле NotchNook.

### 3. Переключение аудиоустройств и микшер громкости
- Быстрое переключение системных устройств вывода звука (встроенные динамики, наушники, AirPods) из выпадающего меню плеера.
- Микшер громкости для приложений, выводящих звук (с определением активных процессов через CoreAudio).

### 4. Полноценная вкладка календаря
- Выделенная вкладка с двухколоночным представлением: список событий на выбранный день и крупная сетка месяца с индикаторами встреч.

### 5. Полная русская локализация
- Переведены все элементы интерфейса: вкладки навигации, плеер, дровер устройств, панель агентов и окно настроек приложения.

---

## Сборка

Для сборки требуется macOS 14.0+ и Xcode:

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -scheme boringNotch -configuration Debug build
```
